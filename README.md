# MAHALA — mechanics test

MAHALA is an Appalachian folk-horror project by Ren Sutherland, set in autumn 1997.

This is a small mechanics test, not a full game or a finished demo. It includes a forest bead search, a clearing with gathering and animal interactions, and a walk home with a short household sequence. The story, art and controls are still being worked on.

## Download

Open **Releases** and download the ZIP for Windows, Linux or Mac. Extract the whole ZIP before starting. You do not need Godot installed.

## Controls

- Arrow keys: move or choose an answer
- E: interact
- Enter / Space: advance dialogue or confirm
- L: listen outdoors
- J: check the current sketchbook clues
- Esc: return to the menu
- R: retry the clearing

Progress saves automatically. A broken protective strand stays broken when retrying. Use **Start over** from the title screen if you want a fresh test.

## Feedback

Please tell me what was unclear, what got stuck, and what you expected to happen. Screenshots help. Include your operating system and the build date. You can use this repository's Issues tab or send feedback to me directly.

The main things I am testing are finding items, understanding interactions, animal responses, navigation, collisions and the homecoming tasks. There are known rough edges. The full sketchbook system and opening sequence are not included yet.

Contains unsettling imagery, animal-like threats and a hostile parent.
